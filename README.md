# 看股票

把台灣證交所的公開資料整理成**可讀、可追溯**的條件篩選工具。
純靜態網頁，零後端，資料由 GitHub Actions 每個交易日自動更新。

## 這是什麼，不是什麼

**是**：一個誠實的篩選器。你設定條件（本益比上限、殖利率下限、法人連買天數…），
它掃全市場列出符合的股票，並標明每一檔是哪幾條條件成立。

**不是**：投顧、明牌、推薦系統。畫面上永遠只會出現「符合條件」與「風險分級」，
不會出現「建議買進」。**符合條件 ≠ 交易指令，判斷永遠是你自己的。**

## 功能

- **自選股**：常看的代號放一起，看收盤、漲跌、量能對比 20 日均量、法人連買天數
- **篩選器**：基本面穩健／籌碼動能兩組條件可個別開關與調整；另有 33 種產業分類與
  「成交熱門／近期強勢／法人連買／放量」四種趨勢標籤；題材搜尋（人工核對的供應鏈名單）
- **個股頁**：近半年日 K、月營收年增率、法人買賣超，以及**風險觀察**——
  用近半年日收盤計算趨勢品質（線性回歸 R²）、年化波動率、最大回撤，合成穩健／波動／賭性堅強分級
- **ETF**：獨立查詢頁，配息紀錄（除息日與入帳日分開標示）、官方前五大持股

## 資料來源

全部取自臺灣證券交易所公開資料：

| 資料 | 端點 |
| :-- | :-- |
| 全市場日收盤 | `openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL` |
| 本益比／殖利率／淨值比 | `openapi.twse.com.tw/v1/exchangeReport/BWIBBU_ALL` |
| 月營收 | `openapi.twse.com.tw/v1/opendata/t187ap05_L` |
| 三大法人買賣超 | `twse.com.tw/rwd/zh/fund/T86` |
| 個股歷史日K | `twse.com.tw/rwd/zh/afterTrading/STOCK_DAY`（前端直接呼叫） |

資料每個交易日 16:30（台北時間）更新一次，**不是即時報價**。
網站頂端固定顯示資料日期，看到日期不對就是排程沒跑成功。

## 架構

```
GitHub Actions（每交易日 16:30）
  → scripts/*.mjs 抓證交所資料 → 寫進 data/*.json → commit → Pages 部署
瀏覽器
  → 讀本 repo 的 data/*.json
  → 個股歷史 K 線另向證交所 rwd API 直接取（該端點有開 CORS）
```

零框架、零打包器、零 npm 依賴——`index.html` / `app.js` / `style.css` 三個檔，
Actions 腳本用 Node 20 內建 fetch。

## 本機執行

```bash
python -m http.server 4601
```

然後開 http://localhost:4601 。

資料管線與測試：

```bash
node scripts/fetch.mjs
node scripts/fetch.test.mjs
node tests/frontend-pure.mjs
```

## 免責聲明

本站僅整理公開市場資訊，**不構成投資建議、要約或招攬**。
所有數值可能因資料來源延遲或錯誤而不準確，任何投資決策與其後果由使用者自行負責。
投資有風險，過去績效不代表未來表現。
